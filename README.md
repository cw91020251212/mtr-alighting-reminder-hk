# 港鐵終點提醒

這是一個可公開分享、手機優先的港鐵行程提醒 Web App。朋友只需開啟網站，再按瀏覽器的「加入主畫面」即可使用；不需要帳戶、不需要 APK，也不會將行程上傳到本專案伺服器。

## 行程規劃與官方預計時間

使用者可以選擇**起點站**和**終點站**，讓程式預先顯示完整的建議站序及港鐵官方行程指南的最短路線預計時間。起點站和終點站只用作規劃、畫圖及提示，不會鎖死實際行程：中途改線、繞路或轉乘均可，程式只會以手機位置安靜記錄最接近的車站。

程式會向港鐵公開行程指南接口讀取最短路線的「預計行程時間」。該數據以港鐵行程指南的平日早上繁忙時段假設為基礎，可能包含等候、車內及轉乘時間；實際行程會受服務狀況和月台／出口步行距離影響，僅供參考。

## 港鐵拓撲路綫圖

程式使用自行繪製的**拓撲路綫圖**：它的作用是清晰表達「哪個站之後是哪個站」、每條綫的方向以及轉車關係，並不按實際地理距離或地圖比例畫出。這正是地鐵系統圖應有的用途。路綫圖由開始時已把整個港鐵網絡和計劃行程畫好，不會等待定位才逐段生成。

路綫圖支援拖動、雙指縮放、加減按鈕、回到「行程」及「全網」檢視。直接點選任何站即可把它設為起點、終點，或加入自訂提示點。未經過站使用淺色；位置確認後站點改為實色。若手機在背景中跳過中間一個或幾個站，當下一次確認位置仍在原計劃站序中時，程式會把中間遺漏站一併補回，避免行程視覺上斷開。

## 多個提示點與提示方式

使用者可用下拉列表或直接在拓撲路綫圖點擊車站，分別設定起點、終點或加入提示點。官方建議路線中的轉車站會自動加入為提示點，並額外加入終點前一站。每個提示點均可獨立設定：

| 模式 | 行為 |
| --- | --- |
| **響鬧＋廣東話** | 本地系統通知、震動及廣東話站名提示。 |
| **淨係廣東話** | 只用瀏覽器語音讀出提示，不顯示系統通知或震動。 |
| **關閉** | 保留設定但不提示。 |

語音採用瀏覽器內建的 `zh-HK` 語音。不同手機和瀏覽器可用的廣東話聲音略有不同；當網頁被系統完全暫停或手機鎖屏，Web App 未必可持續取得定位或播放語音，請以車廂廣播、列車顯示和車站指示為最後確認。

## 外觀、私隱與資料來源

齒輪設定中包含淺色／深色／跟系統、文字大小、廣東話試聽及清除本機紀錄。深色模式採用深灰背景、淺色文字和高對比幼邊線。路線、提示點、已經過站、位置紀錄及顯示設定只保存在使用者自己的瀏覽器 `localStorage`；網站不設帳戶、不使用 Web Push，也不會把位置傳送到本專案伺服器。
