# 港鐵終點提醒

這是一個可公開分享、手機優先的港鐵落車提醒 Web App。朋友只需開啟網站，再按瀏覽器的「加入主畫面」即可使用；不需帳戶、不需安裝 APK，也不會將行程上傳到伺服器。

## 核心使用方式

使用者只需選擇**終點站**，然後開始靜默追蹤。程式不要求使用者預先選擇上車站、固定路線或轉車方式。當位置偵測到使用者接近港鐵車站時，程式會在本機行程圖點亮該站，方便回看實際途經路徑；中途改線、轉車或繞行均不會發出通知。唯一的響鬧規則，是使用者到達所選終點站的**相鄰前一站**時，程式震動並發出一次本地系統通知。若定位直接跳到目的地，亦會補發一次提醒，避免漏報。

啟動後可在「逐站行程」與「港鐵平面圖」之間切換。平面圖以全網絡站點的地理位置顯示路綫；已駛經車站、目前最近站、終點前一站及終點站均以不同顏色標記。使用者可以單指拖動畫面、雙指縮放，或使用右下角的 **＋／－／重設** 按鈕調整圖像大小。

例如終點設定為「荃灣」，程式只有偵測到「大窩口」或已直接到達「荃灣」時才會提示；之前即使經過太和、大埔墟、大學、旺角東、旺角、太子或其他站，也只會安靜地顯示在行程圖上。

## 位置與通知

港鐵站點、地理距離、已經過車站及提醒狀態均只保存在使用者自己的瀏覽器 `localStorage`；網站不設帳戶、不使用 Web Push，也不會把位置傳送到本專案伺服器。程式會要求瀏覽器的「位置」與「通知」權限。

這是 Web App 的技術限制：當手機鎖屏、進入省電模式或瀏覽器被操作系統暫停時，瀏覽器可能停止提供位置更新，因此無法承諾在完全關閉網站的情況下持續追蹤。建議把網站加入主畫面、保持瀏覽器或 PWA 可用，並以車廂廣播、列車顯示及車站指示作最後確認。

## 測試

追蹤啟動後，畫面會顯示一組「測試站」按鈕。它們只會在本機模擬位置進入指定車站，用來在室內確認行程圖及「終點前一站才提示」規則；不會產生或上傳真實位置資料。

## 資料來源

站點及線網參考香港鐵路有限公司的 [MTR Lines and Stations 開放數據](https://opendata.mtr.com.hk/data/mtr_lines_and_stations.csv)；本版本不以 Next Train API 作為「使用者已上車」的證據，避免將某班列車的 ETA 誤判為使用者本人行程。
