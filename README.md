# 港鐵終點提醒

這是一個可公開分享、手機優先的港鐵行程提醒 Web App。朋友只需開啟網站，再按瀏覽器的「加入主畫面」即可使用；不需要帳戶、不需要 APK，也不會將行程上傳到本專案伺服器。

## 使用方式

使用者可以選擇**起點站**和**終點站**，讓程式預先顯示完整的建議站序及港鐵官方行程指南的最短路線預計時間。起點站和終點站僅供規劃與畫圖使用，不會鎖死實際行程：中途改線、繞路或轉乘均可，程式只會以手機位置安靜記錄最接近的車站。

地圖會由開始時已畫出完整港鐵網絡及計劃路線，而不會等待定位資料才逐段畫線。計劃路線內的未經過站使用淺色；位置確認後站點改為實色。若手機在背景中跳過中間一個或幾個站，當下一次確認位置仍在原計劃站序中時，程式會把中間遺漏站一併補回，以免行程圖斷開。

## 多個提示點與提示方式

使用者可用下拉列表或直接在地圖點擊車站，分別設定起點、終點或加入提示點。官方建議路線中的轉車站會自動加入為提示點，並額外加入終點前一站。每個提示點均可獨立設定：

| 模式 | 行為 |
| --- | --- |
| **響鬧＋廣東話** | 本地系統通知、震動及廣東話站名提示。 |
| **淨係廣東話** | 只用瀏覽器語音讀出提示，不顯示系統通知或震動。 |
| **關閉** | 保留設定但不提示。 |

語音採用瀏覽器內建的 `zh-HK` 語音。不同手機和瀏覽器可用的廣東話聲音略有不同；當網頁被系統完全暫停或手機鎖屏，Web App 未必可持續取得定位或播放語音，請以車廂廣播、列車顯示和車站指示為最後確認。

## 地圖、外觀與私隱

互動地圖以 OpenStreetMap 實際地理底圖建立，並以公開車站座標和路綫資料繪製原創的互動覆蓋圖；不複製港鐵官方版權路綫圖。地圖可拖動、縮放，且能直接點選站點。齒輪設定中包含淺色／深色／跟系統、文字大小、廣東話試聽及清除本機紀錄。深色模式採用深灰背景、淺色文字和高對比幼邊線。

路線、提示點、已經過站、位置紀錄及顯示設定只保存在使用者自己的瀏覽器 `localStorage`；網站不設帳戶、不使用 Web Push，也不會把位置傳送到本專案伺服器。

## 預計行程時間

程式會向港鐵公開行程指南接口讀取最短路線的「預計行程時間」，並顯示於規劃卡。該數據以港鐵行程指南的平日早上繁忙時段假設為基礎，可能包含等候、車內及轉乘時間；實際行程會受服務狀況和月台／出口步行距離影響，僅供參考。
