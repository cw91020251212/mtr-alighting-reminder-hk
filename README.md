# 港鐵終點提醒

這是一個可公開分享、手機優先的港鐵行程提醒 Web App。朋友只需開啟網站，再按瀏覽器的「加入主畫面」即可使用；不需要帳戶、不需要 APK，行程和位置不會傳送到本專案伺服器。

## 規劃、追蹤與行程進度

使用者可以選擇**起點站**和**終點站**，讓程式預先取得港鐵行程指南建議的最短行程時間，並設定轉車站和終點前一站提示。起點和終點用於規劃及提示，並不會限制實際行程；使用者可以轉車、繞路或中途更改方向。「反方向」按鈕會直接對調起點和終點，例如把「太和 → 荃灣」改為「荃灣 → 太和」，重新計算官方路線、轉車提示及終點前一站，並清除上一程的已經過站紀錄，讓使用者開始回程。

開始追蹤後，主畫面使用**單一路綫進度圖**顯示已確認經過的站序：一個實色站點接一條直線，再接下一個實色站點。程式不會在未確認行車方向前預先顯示前方站名，只保留沒有站名的空心圓，避免在可轉綫或改方向時誤導使用者。現時所在站會以醒目的藍色圓點標示。開始和停止按鈕固定放在同一個規劃控制區，追蹤狀態亦在按鈕正下方顯示。

若定位由較後站才恢復，程式會以已知站序補回中間已經過的站。例如太和後直接確認沙田時，進度圖會補回大埔墟、大學和火炭，而不會看起來像跳過車站。若實際行程離開原定計劃，程式會以港鐵網絡站序連接最近兩個已確認站，記錄已走過的路段；它不會把未確認的將來行程假裝為已知。

## 全網揀站圖

同一張卡可由「進度」切換至「全網揀站圖」。全網圖的作用只是在規劃時讓使用者直接點選車站，設定起點、終點或新增提示點。它使用自行繪製、參考港鐵系統圖閱讀方式的路綫佈局：以直綫主幹、清楚轉角、分支及轉車交匯表達站序與關係，不按實際地理距離或比例繪製。

全網揀站圖支援拖動、雙指縮放、加減按鈕和「行程／全網」檢視。它顯示完整港鐵網絡，方便選站；追蹤期間的主要閱讀介面則是上方的單一路綫進度圖。

## 提示點與提示方式

使用者可在下拉列表或全網揀站圖設定多個提示點。官方建議路線中的轉車站會自動加入為提示點，並額外加入終點前一站。每個提示點均可獨立設定通知方式。

| 模式 | 行為 |
| --- | --- |
| **響鬧＋廣東話** | 本地系統通知、震動及廣東話站名提示。 |
| **淨係廣東話** | 只用瀏覽器語音讀出提示，不顯示系統通知或震動。 |
| **關閉** | 保留設定但不提示。 |

語音採用瀏覽器內建的 `zh-HK` 語音。不同手機和瀏覽器可用的廣東話聲音略有不同；當網頁被系統完全暫停或手機鎖屏，Web App 未必可持續取得定位或播放語音，請以車廂廣播、列車顯示和車站指示為最後確認。

## 外觀、私隱與資料來源

齒輪設定中包含淺色／深色／跟系統、文字大小、廣東話試聽及清除本機紀錄。深色模式採用深灰背景、淺色文字和高對比幼邊線。路線、提示點、已經過站、位置紀錄及顯示設定只保存在使用者自己的瀏覽器 `localStorage`；網站不設帳戶、不使用 Web Push，也不會把位置傳送到本專案伺服器。
