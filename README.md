# 港鐵落車提醒

這是獨立於 BusPulse HK 的港鐵行程提醒程式。使用者只需選擇上車站、落車站及提前提醒分鐘數；程式以全港鐵網絡圖自動計算較少轉乘的路線，每 20 秒讀取港鐵官方 Next Train API，並使用本地通知提醒轉車或落車。

例如選擇大埔墟到荃灣，系統會計算為東鐵綫到旺角東，步行轉到旺角，再轉乘荃灣綫到荃灣，而不是把行程錯誤地當成只有東鐵綫。

目前支援港鐵官方 API 所列的東鐵綫、屯馬綫、荃灣綫、觀塘綫、將軍澳綫、港島綫、東涌綫、機場快綫、南港島綫及迪士尼綫。程式會按共用轉乘站及旺角東／旺角等實際轉車連接建立全網絡圖，跨線行程會分成多段；到轉乘站提示後由使用者按「已到轉乘站，開始下一段」。

資料來源：香港鐵路有限公司 Next Train API：<https://rt.data.gov.hk/v1/transport/mtr/getSchedule.php>。程式不使用 Web Push、Cloudflare Worker 或外部訂閱服務；頁面內的 Service Worker 只負責本機通知顯示。瀏覽器需要 HTTPS 或 localhost 才能使用定位及系統通知；地下、鎖屏、省電模式及瀏覽器策略可能影響本地計時，實際乘車應以車站廣播及列車顯示為準。

本地預覽：

```bash
python3 -m http.server 8080
```

然後開啟 <http://localhost:8080>。
